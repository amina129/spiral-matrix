# 🐌 Snail Matrix Traversal

A Python implementation that traverses a square matrix in a clockwise spiral (snail) order, with an interactive terminal visualization.

## 📋 Description

This program takes a square matrix (n × n) and returns all elements in a clockwise spiral order, starting from the top-left corner and moving inward layer by layer. It includes a step-by-step terminal visualization that shows the traversal in real-time.

## ✨ Features

- **Clockwise spiral traversal** of any square matrix
- **Interactive terminal visualization** with color-coded elements
- **Step-by-step animation** showing the current position
- **Real-time display** of the spiral order as it builds
- **Support for matrices of any size** (optimized for terminal display)
